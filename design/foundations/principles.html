01
Plain language over jargon
"Where should your movies live?" — not "Select target vdev". Mono type carries the paths and the numbers, so prose never has to.
02
State is never decorative
Teal is a claim that something is online and healthy. Amber asks for a human. If nothing is wrong, say so out loud: "Everything's fine."
03
Primitives, not illustration
Circles, one squashed ellipse, rounded rects. Mark, service icons and mascot share the same primitives, so anything redraws at any size without an illustrator.
04
Drawn, never spun
The boot ring draws out over 1.6s on cubic-bezier(.2,.8,.2,1). A spinner reads as waiting; a drawing reads as progress.
05
One shout per screen
A single purple action. Back and Skip stay quiet at the hairline. Nothing else borrows the identity colour.
06
Cute, but level
The otter earns a sticker; the interface still runs a NAS. Warmth in the type and mark, precision in the data.
