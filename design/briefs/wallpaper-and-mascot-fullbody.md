# Brief: Desktop wallpapers + full-body mascot

## Context
OtterMark is icon-only (head/face). Need a full-body version for wallpaper use,
plus 2-3 wallpaper concepts for the HoltOS live/installed desktop (1920x1080,
dark theme).

## Full-body mascot
- Extend OtterMark into a full-body otter, same style (flat shapes, rounded,
  same palette: holt-current #B14DFF, holt-current-deep #8F2FE0, holt-lilac
  #F4EBFF, holt-deep #0D0B12 for line/shadow work).
- Simple standing or sitting pose, friendly, "cute but level" per the
  existing design principles (foundations/principles.html) — not cartoonish
  or busy.

## Wallpaper concepts (pick 2-3 directions)
- Base: holt-deep (#0D0B12) background, matches installer/Plymouth/SDDM.
- Otter as a large, low-opacity (~5-10%) watermark, corner-anchored (not
  centered — must not compete with desktop icons).
- Optional alternate: abstract pattern derived from OtterMark's shapes
  (ellipses/rounded forms) rather than a literal mascot placement.
- Deliver at 1920x1080 minimum; SVG source preferred so we can rasterize at
  other resolutions ourselves.
