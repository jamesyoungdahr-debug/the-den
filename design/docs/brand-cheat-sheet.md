# HoltOS Brand Cheat Sheet

## Colors
| Name | Hex | Usage |
| :--- | :--- | :--- |
| Deep | `#0D0B12` | Page ground |
| Surface | `#171423` | Panels, rows |
| Raised | `#1D1927` | Inside panels |
| Ink | `#FFFFFF` | Text, system icons |
| Current | `#B14DFF` | Identity, primary action |
| Current Deep | `#8F2FE0` | Shading |
| Lilac | `#F4EBFF` | Cheek pads, whiskers |
| Healthy | `#28E0C8` | Online / Healthy ONLY |
| Warning | `#FFB84D` | Needs a human |

## Typography
- **Nunito**: Display and Body copy (Warmth, friendliness).
- **JetBrains Mono**: Paths, labels, numbers (Technical truth).
